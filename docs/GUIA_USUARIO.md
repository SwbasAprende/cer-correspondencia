# GUÍA DE USUARIO - Sistema CER

## 1. Cómo radicar un documento
1. Ingrese al sistema y vaya a Correspondencia > Nuevo documento.
2. Complete los campos obligatorios (tipo, flujo, remitente, destinatario, asunto, archivo opcional).
3. Haga clic en "Radicar".
4. El sistema asocia el documento al usuario y genera un número de radicado.

## 2. Cómo hacer seguimiento
1. Vaya a Correspondencia > Lista.
2. Use filtros por estado, tipo, prioridad y búsqueda por remitente/destinatario.
3. Haga clic en el documento para ver historial de trazabilidad.

## 3. Cómo generar reportes
1. Acceder a Reportes > Lista.
2. Seleccionar rango de fechas y filtros de estado/flujo.
3. Exportar a Excel si está disponible.

## 4. Preguntas frecuentes
- ¿Puedo ver documentos confidenciales?
  Solo si tiene permiso específico `view_confidenciales`.
- ¿Qué hacer si pierdo mi contraseña?
  Solicitar restablecimiento a través de la administración.
- ¿Cómo se protegen mis datos?
  Con HTTPS, contraseñas hasheadas con Argon2 y auditoría continua.
